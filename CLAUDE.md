# Auth - SDK

`@eva_solutions/auth-sdk` — the public TypeScript client for the EVA Auth Service, consumed by the EVA backends and frontends.

## How we work

pnpm workspace with a private root (`packages/*`):

| Package | Path | Visibility |
|---|---|---|
| `@eva_solutions/auth-sdk` | `packages/auth-sdk/` | Published |
| `@eva_solutions/auth-contracts` | `packages/auth-contracts/` | Private (never published) |

Run scripts as `pnpm run <script>` (`version` and `docs` collide with pnpm built-ins otherwise).

**From the repo root:**

| Script | Use |
|---|---|
| `build` | Build every package (tsdown; one build for every environment, the Auth URL is runtime config) |
| `build:contracts` | Build `auth-contracts` only |
| `type-check` / `test:run` / `test:types` | Build the contract first, then `tsc` / Vitest single run / type tests across packages |
| `lint` | oxlint |
| `fmt` / `fmt:check` | oxfmt on `src/` and `tests/` of every package (write / check only) |
| `changeset` / `version` | Add a changeset / apply version bumps |

**Inside `packages/auth-sdk`:**

| Script / command | Use |
|---|---|
| `dev` / `test` | Build in watch mode / Vitest watch |
| `docs` | Generate TypeDoc into `docs-site/` |
| `attw` | Check published types resolution |
| `npm pack --dry-run` | Inspect the tarball contents (pnpm 11 has no `pnpm pack --dry-run`) |

- **Branches**: `main` publishes — `.github/workflows/release.yml` runs `changeset publish` on every push to `main`, so merge to `main` only what is meant to be released; unreleased work stays on its feature branch. Maintainer steps in [`CONTRIBUTING.md`](CONTRIBUTING.md#releasing-maintainers).
- **Commits**: conventional commits; `feat!` (or `BREAKING CHANGE:`) for breaking changes. No AI attribution, no co-author lines.
- **Style**: oxfmt + oxlint.
- **Docs**: `docs/` is the single source of truth. This repo has no project skills: the directory in this file is the only index. Rules and behavior live in `docs/`, never in this file. Update the affected doc in the same change.
- **Public OSS repo**: never commit secrets, tokens, internal URLs or private topology.
- **Release checklist and consumer propagation**: [`docs/integrations.md`](docs/integrations.md).

## Consumers & server

- **The Auth Service (private)** — the server this SDK talks to (JWKS, public auth routes, S2S `/api/v1/internal/*` as documented in [`docs/api.md`](docs/api.md)).
- **Internal consumer services (private)** — install the SDK as a package.

The contract this SDK exposes and the release/propagation checklist live in [`docs/integrations.md`](docs/integrations.md).

Maintainers with access to the private repos: each private repo documents its side in its own `docs/integrations.md`.

## Directory

### Code map (`packages/auth-sdk/src/`, one entry per subpath export)

| Subpath | Path | Purpose |
|---|---|---|
| `.` | `packages/auth-sdk/src/index.ts` | Core: client, JWT verification, config, shared types |
| `./hono` | `packages/auth-sdk/src/hono/` | Hono middleware, auth routes, helpers |
| `./hono-openapi` | `packages/auth-sdk/src/hono-openapi/` | OpenAPIHono variant of the Hono integration |
| `./generic` | `packages/auth-sdk/src/generic/` | Framework-agnostic request verification and cookies |
| `./react` | `packages/auth-sdk/src/react/` | React provider and hooks |
| `./webhooks` | `packages/auth-sdk/src/webhooks/` | Webhook signature verification and event codes |
| `./admin` | `packages/auth-sdk/src/admin/` | Admin client |
| `./s2s` | `packages/auth-sdk/src/s2s/` | Service-to-service client, signing and verification |

Other in `packages/auth-sdk/`: `tests/` (Vitest), `scripts/` (build and probes), `docs-site/` (generated, gitignored), `CHANGELOG.md` (generated by changesets).

`packages/auth-contracts/`: private API contract package (`src/`, `tests/`); see its `README.md`.

Root: `.changeset/` (pending changesets).
