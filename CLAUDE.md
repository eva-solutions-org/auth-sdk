# Auth - SDK

`@eva_solutions/auth-sdk` — the public TypeScript client for the EVA Auth Service, consumed by the EVA backends and frontends.

## How we work

Package manager: `pnpm`. Run scripts as `pnpm run <script>` (`version` and `docs` collide with pnpm built-ins otherwise).

| Script | Use |
|---|---|
| `build` | Build with tsdown (one build for every environment; the Auth URL is runtime config) |
| `dev` | Build in watch mode |
| `test` / `test:run` / `test:types` | Vitest watch / single run / type tests only |
| `lint` | oxlint |
| `fmt` | oxfmt (writes `src/`) |
| `type-check` | `tsc --noEmit` |
| `changeset` / `version` | Add a changeset / apply version bumps |
| `docs` | Generate TypeDoc into `docs-site/` |
| `attw` | Check published types resolution |

- **Branches**: only `main`. Releases go through changesets and `.github/workflows/release.yml`; maintainer steps in [`CONTRIBUTING.md`](CONTRIBUTING.md#releasing-maintainers).
- **Commits**: conventional commits; `feat!` (or `BREAKING CHANGE:`) for breaking changes. No AI attribution, no co-author lines.
- **Style**: oxfmt + oxlint.
- **Docs**: `docs/` is the single source of truth. This repo has no project skills: the directory in this file is the only index. Rules and behavior live in `docs/`, never in this file. Update the affected doc in the same change.
- **Public OSS repo**: never commit secrets, tokens, internal URLs or private topology.
- **Release checklist and consumer propagation**: [`docs/integrations.md`](docs/integrations.md).

## Consumers & server

- **The Auth Service (private)** — the server this SDK talks to (JWKS, public auth routes, S2S `/internal/*` as documented in [`docs/api.md`](docs/api.md)).
- **Internal consumer services (private)** — install the SDK as a package.

The contract this SDK exposes and the release/propagation checklist live in [`docs/integrations.md`](docs/integrations.md).

Maintainers with access to the private repos: each private repo documents its side in its own `docs/integrations.md`.

## Directory

### Code map (`src/`, one entry per subpath export)

| Subpath | Path | Purpose |
|---|---|---|
| `.` | `src/index.ts` | Core: client, JWT verification, config, shared types |
| `./hono` | `src/hono/` | Hono middleware, auth routes, helpers |
| `./hono-openapi` | `src/hono-openapi/` | OpenAPIHono variant of the Hono integration |
| `./generic` | `src/generic/` | Framework-agnostic request verification and cookies |
| `./react` | `src/react/` | React provider and hooks |
| `./webhooks` | `src/webhooks/` | Webhook signature verification and event codes |
| `./admin` | `src/admin/` | Admin client |
| `./s2s` | `src/s2s/` | Service-to-service client, signing and verification |

Other: `tests/` (Vitest), `scripts/` (probes), `.changeset/` (pending changesets), `docs-site/` (generated, gitignored).
